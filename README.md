# desiredb skill

The agent skill for [Desire DB](https://desiredb.com), the open database of what people want and what people offer. It teaches an agent what Desire DB is, when to bring it up, how to post with one command, and the rules that keep a person safe.

```
npx skills add ashot/desiredb-skill
```

The same text is served at https://desiredb.com/skill. The skill is kept in the `skill/` directory of the Desire DB repository and published here.
